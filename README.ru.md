# Mindbattle

[English](README.md) · [Русский](README.ru.md)

Mindbattle — браузерная интеллектуальная игра для компании на одном экране, одиночного забега или партии с телефонами и общим экраном. Локальный Node.js-сервер обслуживает игру и API обратной связи. Интерфейс сейчас на русском языке.

**[Играть онлайн](https://mindbattle.afonasev.tech/)**

## Режимы

| Режим | Игроки и устройства | Как играть |
| --- | --- | --- |
| Классика | 2–4 команды у одного компьютера | Команды одновременно отвечают на одни и те же вопросы. Две команды могут использовать разные клавиатурные схемы; остальным нужны совместимые геймпады. |
| Соло | Один игрок на компьютере или телефоне | Бесконечный забег с жизнями, рискованными вопросами и локальной таблицей рекордов. Телефонную версию можно установить как PWA и запускать офлайн после первого открытия с интернетом. |
| Сетевая партия | 2–12 игроков с телефонами и один общий экран | Общий экран создаёт код комнаты. Игроки входят с телефонов; сервер согласует вопросы, ответы, таймеры и переподключения. Общий экран не считается игроком. |

Сетевой режим реализован, но плейтест с реальным общим экраном и несколькими физическими телефонами ещё не закрыт. Автоматические браузерные тесты его не заменяют.

## Локальный запуск

Нужны **Node.js 20.19+** и npm. Для игры на общем экране целевая платформа — актуальный desktop Chromium.

```bash
npm ci
npm run dev
```

Откройте адрес из вывода сервера, обычно `http://127.0.0.1:4173`. Проверка production-сборки на своей машине:

```bash
npm run build
npm run preview
```

По умолчанию сервер слушает `127.0.0.1:4173`. Адрес и порт меняются через `MINDBATTLE_HOST` и `MINDBATTLE_PORT`. Чтобы телефоны открыли сетевую игру на локальном сервере, разрешите серверу слушать доступный сетевой интерфейс и используйте LAN-адрес компьютера: `127.0.0.1` доступен только на нём самом.

Анонимные оценки вопросов по умолчанию записываются в `data/difficulty-feedback.ndjson`; путь можно изменить через `MINDBATTLE_FEEDBACK_PATH`. Ход партии и соло-рекорды хранятся в браузере.

## Управление

- В классике доступны `WASD`, стрелки и совместимые геймпады с раскладками Xbox, PlayStation или Nintendo. У каждой команды — своё назначенное управление.
- Ответ выбирается по положению: вверх, вправо, вниз или влево. `Escape` открывает паузу.
- Соло на телефоне использует касания. В сетевой партии общий экран показывает комнату, а каждый игрок отвечает со своего телефона.

## Проверки

```bash
npm run check          # типы, unit-тесты и сборка
npm run content-check  # проверка каталога вопросов
npm run test:browser    # браузерные сценарии Playwright
```

Игровые правила отделены от представления, состояние сериализуемо, а случайность воспроизводится по seed. Основные части кода: `src/domain/`, `src/application/`, `src/network/` и `server/`.

## Процесс разработки и поставка

В [workflow/project.json](workflow/project.json) записаны общий OpenSpec planning store, проверки и политика релизов. Каноническая спецификация игры и история OpenSpec находятся в отдельном planning store; [docs/GAME_SPEC.md](docs/GAME_SPEC.md) указывает путь. После проверки фичи её ветка отправляется в `origin`, затем изменения интегрируются и отправляются в `main` с записью доказательств в change. Production-деплой требует отдельного явного разрешения, а ручная приёмка проводится отдельно от автоматических проверок.

Владелец выкладывает игру на `mindbattle.afonasev.tech` командой `make deploy` с настроенным VPS и SSH-профилем. Команда собирает приложение, обновляет сервер, перезапускает сервис и проверяет локальную доступность; для локальной игры она не нужна. Точные действия описаны в [scripts/deploy.sh](scripts/deploy.sh).
