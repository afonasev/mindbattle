# Game QA

Прочитай этот файл перед player-visible, input, multiplayer, audio или browser-QA задачей.

- Не подменяй фактический мультиплеерный плейтест одиночным сценарием, автотестом, сборкой или виртуальным вводом, когда изменены multiplayer-правила, физический ввод, device-specific UI или другой сценарий, зависящий от устройств.
- Не требуй повторный физический плейтест для изменения, которое не затрагивает логику или взаимодействие на физических устройствах; в таком случае достаточно релевантных автоматических проверок и browser QA. Для браузерной версии используй in-app Browser; для изменённого управления устройствами нужен заявленный физический сценарий.
- Все проверки и плейтесты по умолчанию проводи с выключенным звуком. Включай звук только тогда, когда тест непосредственно проверяет аудио или связанное со звуком поведение.
- После любого визуального изменения приложи актуальные скриншоты результата в отчёте пользователю. Скриншоты дополняют, но не заменяют проверку взаимодействия в реальной целевой среде.
