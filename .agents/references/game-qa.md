# Game QA

Прочитай этот файл перед player-visible, input, multiplayer, audio или browser-QA задачей.

- Не подменяй фактический мультиплеерный плейтест одиночным сценарием, автотестом, сборкой или виртуальным вводом.
- Любое изменение взаимодействия проверяй в реальной целевой среде. Для браузерной версии используй in-app Browser; для управления устройствами нужен заявленный физический сценарий.
- Все проверки и плейтесты по умолчанию проводи с выключенным звуком. Включай звук только тогда, когда тест непосредственно проверяет аудио или связанное со звуком поведение.
- После любого визуального изменения приложи актуальные скриншоты результата в отчёте пользователю. Скриншоты дополняют, но не заменяют проверку взаимодействия в реальной целевой среде.
