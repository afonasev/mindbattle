# Установщик

Пакет: `installer`. Версия: **0.1.0**. Зависимости: нет.

Установка настольной игры, штатный запуск, повторная установка, восстановление и удаление. Пакет не зависит от игрового меню и настроек и не навязывает инструмент создания установщика.

- [Требования](requirements.md)
- [Платформенные правила](platforms.md)
- [Критерии приёмки и публикации](acceptance.md)
- [Как подключить](usage.md)

[Обновления](../updates/README.md) подключаются поверх установленного приложения. Браузерная поставка не входит в контракт этого пакета.
