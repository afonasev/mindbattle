# Платформы установщика

Версия: **0.1.0**. Уточняет INSTALLER-FLOW-01, INSTALLER-LAUNCH-01 и INSTALLER-REMOVE-01.

| Платформа | Установка и запуск | Удаление |
|---|---|---|
| Windows | Штатный установщик, стандартный каталог приложения, запись в меню «Пуск», возможность создать ярлык на рабочем столе | Штатное удаление приложения и его ярлыков/записей установки |
| macOS | DMG с понятным переносом приложения в Applications; запуск приложения через Finder и системный поиск | Штатное удаление приложения; пользовательские данные сохраняются |
| Другие настольные ОС | Проект описывает обычный для платформы пакет, каталог, точку запуска и права | Проект описывает штатный способ удаления |

Это требования к результату, а не выбор конкретного packaging-инструмента. Способ установки может использовать средства ОС вместо собственного мастера.

Проект явно заявляет поддерживаемые версии ОС и архитектуры. Universal-пакет отмечается как таковой; сборка под одну архитектуру не доказывает работу на другой.

Для разработки и активного тестирования действует исключение INSTALLER-TRUST-01: допускается неподписанная публикация с понятным описанием ограничений. Для подписанной поставки отдельно фиксируется фактическая проверка подписи и платформенного допуска.

Платформенные проверки могут выполняться пользователем. Недоступность платформы у агента фиксируется как ожидающая проверка и не требует имитации успешного результата.
