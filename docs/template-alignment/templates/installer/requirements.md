# Требования к установщику

Пакет: `installer`, версия **0.1.0**.

### INSTALLER-PACKAGE-01 — Готовая поставка

Для каждой заявленной ОС и архитектуры выпускается готовый пакет в GitHub Releases игры. Имя файла позволяет определить игру, версию, ОС и архитектуру. Установка не требует Unity Editor, инструментов разработки или ручного копирования зависимостей. Необходимые runtime-зависимости включаются в поставку либо устанавливаются штатным способом.

### INSTALLER-IDENTITY-01 — Единая иконка

Игра и установщик используют одну и ту же иконку. Допускаются технические варианты размеров и форматов для платформ без изменения самого изображения. Иконка приложения и его штатных ярлыков соответствует этой же идентичности.

### INSTALLER-FLOW-01 — Понятная установка

Используется обычный для платформы сценарий, описанный в [platforms.md](platforms.md). Название игры, издатель, версия и назначение установки понятны пользователю. По умолчанию используется стандартное расположение приложения; выбор другого каталога допускается, если его поддерживает способ установки.

### INSTALLER-FLOW-02 — Предварительные проверки

До изменения установки проверяются совместимость ОС и архитектуры, необходимые права и свободное место. Ошибки объясняют причину и доступное действие. На платформах с установкой средствами ОС проверки могут выполняться этими средствами; отдельный мастер не обязателен.

### INSTALLER-RIGHTS-01 — Минимальные права

Повышенные права используются только для необходимых операций установки. После установки игра запускается с обычными правами пользователя. Обычная работа игры не требует записи в защищённый каталог приложения.

### INSTALLER-TRUST-01 — Подпись и тестовая поставка

Для обычной поставки приложение и установочный пакет подписываются согласно требованиям целевой платформы; установка не требует отключать системную защиту. Подпись и платформенный допуск проверяются для подписанной поставки.

На стадии разработки и активного тестирования допускается публиковать приложение и установщик без подписи. Это, возможные системные предупреждения и инструкция запуска явно указываются в описании релиза. Такая поставка не объявляется прошедшей проверку подписи или платформенного допуска. Исключение для подписи приложения не отменяет проверку доверия к автоматически устанавливаемому обновлению по пакету `updates`.

### INSTALLER-CONTENT-01 — Полный состав и точка входа

Установка содержит всё необходимое для обычного запуска. Если используется launcher, штатные ярлыки и точки входа запускают игру через него; отдельный ручной запуск launcher не требуется. При подключении `updates` устанавливается необходимый компонент обновления.

### INSTALLER-CONTENT-02 — Сведения об установке

Установленная игра содержит однозначные сведения о своей версии, платформе, архитектуре и канале поставки. Расположение файлов, способ определения установленной версии и штатная точка входа документированы для обновляющего компонента.

### INSTALLER-LAUNCH-01 — Штатный запуск

Игра доступна через стандартную точку запуска платформы. Первый запуск открывает обычный пользовательский сценарий. Повторный запуск не требует установщика, повторного скачивания или GitHub, если сама игра поддерживает работу без сети. Запуск после установки допускается только как явно обозначенный выбор пользователя.

### INSTALLER-DATA-01 — Разделение приложения и данных

Настройки, сохранения, рекорды, лабораторные профили и другие пользовательские данные отделены от файлов приложения и находятся в стандартном доступном для записи каталоге платформы. Установка, повторная установка и замена приложения сохраняют данные. Временные файлы установки не смешиваются с постоянными данными игры.

### INSTALLER-REINSTALL-01 — Повторная установка

Распознаётся существующая установка. Повторная установка той же версии позволяет восстановить файлы приложения. Установка новой версии поверх существующей сохраняет данные и штатные точки запуска. Способ распознавания и восстановления может обеспечиваться установщиком или штатным механизмом ОС.

### INSTALLER-REINSTALL-02 — Работающая игра и каналы

Файлы работающей игры не заменяются: пользователь получает предложение закрыть её и продолжить. Стабильная и тестовая поставки не перезаписывают друг друга случайно; правила их совместной установки определяет проект. Установка старой версии не выполняется незаметно: последствия для совместимости данных определяются отдельно.

### INSTALLER-RECOVERY-01 — Отмена и сбои

Отмена и прерывание не оставляют приложение объявленным успешно установленным и не повреждают прежнюю рабочую установку. Частичные файлы не становятся штатной точкой запуска. При невозможности автоматического восстановления показаны понятное состояние и способ повторить установку. Принадлежащие установке временные файлы освобождаются после завершения или отмены.

### INSTALLER-REMOVE-01 — Удаление

Приложение удаляется стандартным способом платформы вместе с принадлежащими ему ярлыками и записями установки. Пользовательские данные сохраняются по умолчанию. Их удаление допускается только как отдельный явный выбор с перечислением последствий. Другие игры, общие каталоги и чужие файлы не затрагиваются.

### INSTALLER-ARGS-01 — Параметры и тихий запуск

Штатная точка запуска и launcher передают параметры приложению. Общий прикладной параметр — `-muted`; Unity Editor/Player дополнительно получает `-noaudio`, то есть запускается с `-noaudio -muted`.

Тихий режим обрабатывается до инициализации аудио и первого возможного воспроизведения, включая заставку, меню, музыку и эффекты, и действует всю сессию. Сохранённые громкости, системная громкость и звук других приложений не меняются. Документация содержит точную команду тихого запуска установленной игры. Позднее отключение звука не считается поддержкой контракта.

### INSTALLER-QA-01 — Проверки по изменениям

Приёмка — каталог сценариев, а не обязательный повтор всего набора после каждой правки. По diff относительно записанной проверенной версии выбираются проверки затронутых упаковки, установки, запуска и зависимостей. Результаты незатронутых сценариев допускается использовать повторно с указанием проверенной версии и платформы.

Проверки на других платформах может выполнить пользователь. До получения результата они остаются ожидающими проверки; результат одной ОС или архитектуры не подменяет остальные. Выполненные, повторно используемые и ожидающие проверки перечисляются отдельно.

### INSTALLER-RELEASE-01 — Публикация без полного регресса

Полный регрессионный запуск всех тестов приложения не является обязательным условием сборки или публикации. Изменения, вошедшие в последнюю версию `main`, считаются уже проверенными; повторное тестирование приложения ради публикации не требуется. Это не подменяет необходимые проверки изменённого установщика и фактически не выполненную платформенную приёмку.

Полный прогон выполняется только по отдельной явной команде человека. Сборка установщика, поставка и публикация требуют соответствующей явной команды; сами требования не разрешают их запуск.
