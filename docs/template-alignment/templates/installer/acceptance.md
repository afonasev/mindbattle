# Приёмка установщика и публикация

Версия: **0.1.0**.

Перед проверкой запишите baseline, diff, затронутые зависимости, выбранные сценарии и команды с причиной выбора. Не запускайте все сценарии автоматически: для незатронутых допускается использовать прежние результаты с версией и платформой. Полный регресс приложения не нужен для публикации: попавшие в `main` изменения считаются проверенными.

| Сценарий | Ожидаемый результат | Требования |
|---|---|---|
| Состав пакета | Верные игра, версия, ОС, архитектура и зависимости; установка без dev-инструментов | INSTALLER-PACKAGE-01, INSTALLER-CONTENT-01 |
| Иконки | Игра, установщик и штатные ярлыки используют одно изображение | INSTALLER-IDENTITY-01 |
| Чистая установка | Понятный платформенный сценарий, каталог, сведения об установке и точки запуска | INSTALLER-FLOW-01, INSTALLER-CONTENT-02, INSTALLER-LAUNCH-01 |
| Неподходящая ОС/архитектура, нехватка места и прав | Понятный отказ до повреждения установки | INSTALLER-FLOW-02, INSTALLER-RIGHTS-01 |
| Подписанная поставка | Зафиксированы подпись и платформенный допуск | INSTALLER-TRUST-01 |
| Неподписанная dev/test-поставка | В релизе указаны отсутствие подписи, предупреждения и инструкция; нет заявления о пройденной проверке подписи | INSTALLER-TRUST-01 |
| Обычный и повторный запуск | Игра работает с обычными правами; при допустимом offline-режиме не требует GitHub | INSTALLER-RIGHTS-01, INSTALLER-LAUNCH-01 |
| Пути с пробелами и нелатинскими символами | Установка и запуск работают из поддерживаемых путей | INSTALLER-FLOW-01, INSTALLER-LAUNCH-01 |
| Данные | Приложение и данные разделены; установка сохраняет предпочтения, прогресс и профили | INSTALLER-DATA-01 |
| Повторная установка / новая версия поверх | Восстановлены файлы, сохранены данные и ярлыки | INSTALLER-REINSTALL-01 |
| Игра запущена / другой канал / downgrade | Нет замены работающих файлов, случайного смешения каналов и незаметной установки старой версии | INSTALLER-REINSTALL-02 |
| Отмена, прерывание и повтор | Прежняя установка работоспособна; частичная не объявлена установленной; временные файлы очищены | INSTALLER-RECOVERY-01 |
| Удаление | Удалены только файлы приложения; данные сохранены либо удалены отдельным явным выбором | INSTALLER-REMOVE-01 |
| Тихий запуск через штатную точку входа | `-muted` передан; Unity получает также `-noaudio`; звук отключён до инициализации, preferences не меняются | INSTALLER-ARGS-01 |
| Выбор проверок и публикация | Проверены затронутые контракты; старые результаты и ожидающие платформы отделены; full не запущен без команды | INSTALLER-QA-01, INSTALLER-RELEASE-01 |

Автоматические запуски игры выполняются без слышимого звука с самого старта. Аудиологика проверяется offline/file-методом либо с отключённым выводом при сохранённом контракте. Неработающий тихий параметр — незакрытое требование, а невозможная в тихом режиме проверка — NotRun с причиной.

Для каждого результата укажите версию/commit и ветку приложения, идентичность пакета, ОС/архитектуру, способ проверки и исполнителя (агент или пользователь). Отдельно перечислите выполненные проверки, прежние результаты и ожидающие проверки. Сборка, тест установки и human/device acceptance не взаимозаменяемы.

Публикация допускается без полного регресса приложения; это не означает, что ожидающие платформенные проверки уже прошли. Состояние поставки и ограничения сообщаются явно. Для подписанной и неподписанной поставок выбирается соответствующий сценарий, а не оба как обязательный gate.
