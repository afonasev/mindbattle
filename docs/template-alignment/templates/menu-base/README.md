# Базовое меню

Пакет: `menu-base`. Версия: **0.1.0**. Зависимости: нет.

Задаёт общую структуру и UX меню. Правила распространяются на главное меню, вложенные страницы, диалоги, игровые меню, настройки, справку и будущую лабораторию.

- [Требования](requirements.md)
- [Критерии приёмки](acceptance.md)
- [Как подключить](usage.md)

Пакет не задаёт художественный стиль, состав режимов игры, механику сохранения/загрузки, лаборатории или обновления приложения. Настройки описаны в отдельном пакете [settings](../settings/README.md).
