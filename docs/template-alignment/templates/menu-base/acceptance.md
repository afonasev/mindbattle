# Приёмка базового меню

Версия: **0.1.0**. Критерии проверяют требования [menu-base](requirements.md).

| Сценарий | Ожидаемый результат | Требования |
|---|---|---|
| Первый вход | Название, основное действие и настройки видимы; начальный фокус осмыслен | MENU-STRUCTURE-01, MENU-FOCUS-01 |
| Дополнительные маршруты | Подключены только предусмотренные проектом функции; сохранение/загрузка не добавлены автоматически из базового пакета | MENU-STRUCTURE-02 |
| Недоступный маршрут | Причина понятна без hover; активация не меняет состояние | MENU-STRUCTURE-03 |
| Полный проход каждым устройством | Все доступные действия выполняются мышью, стрелками/подтверждением/Esc и геймпадом; Tab не требуется | MENU-INPUT-01, MENU-INPUT-02 |
| Возврат из вложенной страницы | Восстановлены вызывающий экран, фокус и положение внутренних списков | MENU-FOCUS-02 |
| Диалог или раскрытый список | Ввод получает верхний контекст; первое действие «назад» закрывает его | MENU-INPUT-03, MENU-FOCUS-02 |
| Удержание при переходе | Открывающая кнопка не активирует следующее действие; операция не запускается дважды | MENU-INPUT-04 |
| Ввод текста, если есть | Текст и стрелки работают в поле; ввод с геймпада не требует клавиатуры | MENU-INPUT-05 |
| Внутренний длинный список | Фокусируемый элемент раскрывается; экран, заголовок и основные действия не прокручиваются | MENU-FOCUS-03, MENU-LAYOUT-02 |
| Смена устройств | Сохраняются фокус и значения; неактивный подключённый pad и дрейф не меняют режим | MENU-DEVICE-01, MENU-DEVICE-02 |
| Подсказки | Видимы только при активном pad; размещены на соответствующих действиях, где возможно; glyph и действие совпадают | MENU-HINTS-01, MENU-HINTS-02, MENU-HINTS-03 |
| Повторяющиеся действия | «Назад» и аналогичные действия имеют одинаковую позицию, оформление и семантику на сопоставимых экранах | MENU-LAYOUT-01 |
| Низкое, узкое, широкое окно | Нет перекрытий, обрезанных popup и недоступных действий; прокручиваются только внутренние области | MENU-LAYOUT-02, MENU-LAYOUT-03 |
| Ошибка и повтор | Сообщение оформлено в стиле игры, объясняет следующий шаг; после закрытия восстановлен фокус | MENU-STATE-01, MENU-STATE-02 |
| Меню во время игры | Игровой ввод не проходит через меню; пауза и онлайн-полномочия соответствуют контракту проекта | MENU-INPUT-03, MENU-PAUSE-01 |

## Как фиксировать результат

Для применимых сценариев запишите ревизию игры и шаблона, устройство, размер экрана, способ проверки и результат. Для неприменимых сценариев укажите причину.

Автоматические проверки навигации дополняются визуальной проверкой компоновки и подсказок. Эмуляция геймпада не доказывает удобство на физическом устройстве. Отсутствие запуска или доказательств фиксируется как NotRun, а не успешная приёмка.

Автоматические запуски выполняются без звукового вывода с самого старта. Выбирайте необходимый набор проверок затронутого поведения; этот checklist не разрешает полный прогон тестов, сборку для поставки или публикацию игры.
