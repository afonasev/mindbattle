# Приёмка обновлений

Версия: **0.2.0**. Дополняет приёмку `installer` и `menu-base` только затронутыми сценариями.

Перед запуском фиксируются baseline, diff, команды и причины выбора affected-набора. Полный регресс приложения для публикации не обязателен; изменения `main` считаются проверенными. Незатронутые результаты используются повторно с указанием версии/платформы. Проверки на других платформах может выполнить пользователь.

| Сценарий | Ожидаемый результат | Требования |
|---|---|---|
| Источник релизов | Проверка через GitHub, assets выбранного выпуска; публичная игра не требует аккаунта/встроенного секрета | UPDATES-SOURCE-01 |
| Версии, платформы и каналы | Актуальная версия не обновляется; новые подходящие предлагаются; draft, чужой канал/платформа и downgrade исключены | UPDATES-SELECT-01 |
| Запуск, длинная сессия и возврат в меню | Единственная стартовая проверка не задерживает меню; ручной проверки, таймера и повторного обнаружения версии нет | UPDATES-CHECK-01 |
| Offline, ошибки и API limit | Установленная игра доступна; ошибка не выдана за актуальность; следующая проверка только при новом запуске | UPDATES-CHECK-02 |
| Игнорирование версии | Нет скачивания, установки, таймера и блокировки игры; пользовательских настроек обновления нет | UPDATES-CONSENT-01 |
| Принятое обновление и выход | Скачивание после «Обновить»; подготовка автоматическая; применение на закрытии/следующем запуске либо явном перезапуске | UPDATES-CONSENT-01 |
| Матч, редактор, лаборатория и выход во время загрузки | Во время матча нет скачивания; начатая загрузка приостановлена и продолжена в меню без новой проверки; нет принудительного выхода и задержки выхода ради загрузки | UPDATES-FLOW-01 |
| Состояния UI | Видимый прогресс скачивания; «Перезапустить» только после скачивания и проверки; текущая версия фактически запущена, фокус не перехвачен; ручной проверки нет | UPDATES-UI-01 |
| Отмена/обрыв/повтор скачивания | Рабочая игра не меняется; неполный пакет не объявляется готовым; нет двойной операции и подмены выбранной версии | UPDATES-DOWNLOAD-01 |
| «Что нового»: несколько версий и язык | Доступны последние версии и установленная, номер/дата и RU/EN на языке меню; внутренняя прокрутка; запрос истории не меняет кандидата и не идёт в матче | UPDATES-HISTORY-01 |
| Публикация changelog | В описании GitHub Release есть RU/EN, сформированные по истории канала; одинаковые изменения сгруппированы и изложены для игрока, не списком коммитов | UPDATES-CHANGELOG-01 |
| Неверная подпись, checksum, платформа и несовместимость | Пакет отклонён; проверка повторена перед активацией; прежняя версия сохранена | UPDATES-TRUST-01 |
| Нехватка места, права, прерывание установки | Нет частичной рабочей установки; запуск игры без постоянного повышения прав | UPDATES-INSTALL-01 |
| Бесшовная установка и отмена перезапуска | Не открывается мастер, не нужен ручной перенос; «Перезапустить» применяет готовую версию и запускает игру; отмена выхода сохраняет игру и готовый пакет | UPDATES-INSTALL-02 |
| Сохранность и миграция данных | Настройки, прогресс и профили сохранены; восстановление учитывает изменённый формат данных | UPDATES-DATA-01 |
| Неудачный старт новой версии | Доступен возврат; предыдущая версия сохранена до startup-подтверждения; нет цикла повторной установки | UPDATES-RECOVERY-01 |
| Тихий перезапуск после обновления | Переданы `-muted` и для Unity `-noaudio`; ни один этап не включает слышимый вывод | UPDATES-ARGS-01 |
| Полнота релиза и отдельные компоненты | Неполный релиз не допускается; версия не подменяется; контент/оболочка не смешиваются | UPDATES-RELEASE-01 |
| Объём QA и публикация | Выбран affected-набор; прежние и ожидающие результаты названы отдельно; full без команды не запускался | UPDATES-QA-01 |

Запишите ветку, commit, исходную/целевую версии, идентичность пакетов, ОС/архитектуру, исполнителя и фактический результат. Успешный запуск процесса не равен подтверждённой установке/совместимости данных. Недоступная проверка — NotRun или ожидает пользователя; это не Passed.

Для сетевых и аварийных сценариев допустим изолированный тестовый источник/fixture при сохранении контракта GitHub. Фактический путь получения релиза и установки проверяется отдельно, когда затронут. Автоматическая аудиопроверка — offline/file или с отключённым выводом; неработающий startup-параметр остаётся незакрытым требованием.
