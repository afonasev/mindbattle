# Обновления

Пакет: `updates`. Версия: **0.2.0**. Зависимости: [installer](../installer/README.md) **0.1.0** и [menu-base](../menu-base/README.md) **0.1.0**.

Обновление установленной настольной игры через GitHub Releases: автоматическая проверка, предложение новой версии, скачивание по действию игрока и безопасное применение подготовленного обновления после закрытия игры или перед следующим запуском.

Пакет **не зависит от `settings`**. Пользовательских переключателей, интервалов и режимов обновления нет. Проверка выполняется только один раз при запуске; ручной проверки и повторных проверок в этой сессии нет. Во время матча обновление не скачивается. Игрок может игнорировать предложение и пользоваться установленной версией. Автоматизация не означает принудительное скачивание или завершение игры.

- [Контракт релиза и двуязычный changelog](release-format.md)
- [Критерии приёмки](acceptance.md)
- [Как подключить](usage.md)

Установка и пользовательские данные наследуются из `installer`. Применение браузерной версии, service worker и кеширование веб-хостинга требуют отдельного контракта и не входят в этот пакет.
