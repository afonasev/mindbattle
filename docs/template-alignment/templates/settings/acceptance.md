# Приёмка настроек

Версия: **0.1.1**. Проверяются также применимые [критерии menu-base](../menu-base/acceptance.md).

| Сценарий | Ожидаемый результат | Требования |
|---|---|---|
| Разбор каталога | Для каждой опции определены применимость и контракт; применимые опции реализованы | SETTINGS-CATALOG-01, SETTINGS-CONTROL-02 |
| Главное меню → настройки; Esc → настройки | Состав, значения и поведение одинаковы; исключения явно согласованы | SETTINGS-ENTRY-01 |
| Возврат в игровое меню | Восстановлены контекст и фокус; барьер паузы не снят настройками | SETTINGS-ENTRY-01, SETTINGS-BASE-01 |
| Разделы и длинный список | Группировка понятна, небольшие разделы могут быть объединены; прокручивается только область параметров | SETTINGS-GROUPS-01 |
| Изменение каждым устройством | Переключатели, слайдеры и списки доступны; число, единица и состояние видимы | SETTINGS-CONTROL-01, SETTINGS-CONTROL-02 |
| Проверка графики и баланса | Обычные настройки дают качество/включение эффектов; тонкие коэффициенты и баланс не смешаны с ними | SETTINGS-SCOPE-01 |
| Несколько участников, если есть | Общие и личные значения имеют правильную область; открытые панели не показывают устаревшие значения | SETTINGS-CONTROL-03 |
| Изменение и перезапуск | Значения применены и сохранены, включая ноль и false | SETTINGS-PERSIST-01, SETTINGS-PERSIST-03 |
| Отложенная опция, если есть | Момент применения явно показан; действующее и выбранное значения различимы | SETTINGS-PERSIST-02 |
| Ошибка сохранения | Нет ложного сообщения об успехе; ошибка оформлена в стиле игры; корректное предыдущее состояние сохранено | SETTINGS-PERSIST-03 |
| Старые/некорректные предпочтения и другой экран | Допустимые значения сохранены, отсутствующие получают default, недоступный режим безопасно заменяется | SETTINGS-PERSIST-03 |
| Смена экранного режима | Подтверждение сохраняет выбор; отмена и отсутствие подтверждения возвращают прежний режим | SETTINGS-DISPLAY-01 |
| Громкость канала и общая громкость в нуле | Отключается соответствующий канал или весь звук; отдельного mute в меню нет | SETTINGS-AUDIO-01 |
| Тихий запуск | `-muted` (Unity также `-noaudio`, браузер `?muted=1`) обработан до инициализации аудио; предпочтения не изменены, обычный запуск сохраняет пользовательские громкости | SETTINGS-AUDIO-02 |
| Сброс раздела / всех предпочтений | Область ясна; defaults восстановлены по правилам применения; прогресс, данные, профили и согласие не изменены | SETTINGS-RESET-01 |
| Shortcut сброса, если назначен | Подсказка на действии соответствует pad; shortcut работает только в своём контексте; есть доступ мышью и клавиатурой | SETTINGS-RESET-02 |
| Открытие графической справки | Отдельный экран, клавиатура/мышь вместе, геймпад отдельно; возврат восстанавливает настройки | SETTINGS-HELP-01, SETTINGS-HELP-02 |
| Проверка изображений | Основные иллюстрации сгенерированы, стиль соответствует игре, текст и выноски читаемы | SETTINGS-HELP-03, SETTINGS-HELP-06 |
| Проверка содержания справки | Только игровые действия, без инструкций навигации меню; назначения и жесты совпадают с runtime | SETTINGS-HELP-04, SETTINGS-HELP-05 |

## Доказательства

Запишите ревизию игры и шаблонов, проверенные опции, устройства, размеры экрана и результаты. Ошибки хранения и миграции можно проверять изолированными тестовыми данными. Для справки и компоновки нужны просмотренные снимки; для поведения на физическом контроллере — проверка на таком устройстве.

Автоматические проверки звука выполняются без слышимого вывода с самого старта: offline/file-проверка или отключённый вывод на устройство. Позднее обнуление громкости после запуска не доказывает тихий старт. Если тихий режим не позволяет проверить аудиоконтракт, результат — NotRun с причиной, а не успешная проверка.

Этот checklist не требует полного тестового прогона, Player-сборки или публикации. Необходимые проверки выбираются по затронутому поведению; отдельные build, device и human acceptance результаты фиксируются независимо.
