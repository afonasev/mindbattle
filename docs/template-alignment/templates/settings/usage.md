# Как подключить настройки

Это инструкция для подключения `settings`, а не ещё один источник требований конкретной игры. Заполненное описание хранится в её репозитории.

## Порядок подключения

1. Подключите `menu-base`; зафиксируйте версии обоих пакетов и точный commit шаблонов.
2. Для каждой строки [каталога](options.md) определите применимость. Применимые опции реализуйте; для остальных запишите причину.
3. Для каждой применимой опции определите ключ, название, группу, default, диапазон/варианты и шаг, область действия, зависимости и момент применения.
4. Определите разделы. Малые группы можно объединить в «Общее» или «Главное».
5. Опишите хранение и совместимость предпочтений, обработку ошибок и безопасную смену экрана.
6. Укажите общие/личные настройки и права участников. Проверьте одинаковый состав из главного и игрового меню; запишите согласованные исключения.
7. Опишите сброс раздела и всех предпочтений. Если есть shortcut геймпада, задайте его контекст и подсказку на экранном действии.
8. Документируйте точную команду с `-muted`; для Unity — с `-noaudio -muted`, для браузера — URL с `?muted=1`, обработанным до autoplay.
9. Определите игровые назначения клавиатуры, мыши и геймпада. Сгенерируйте и проверьте изображения [справки](controls-help.md). Навигацию меню в неё не включайте.
10. Зафиксируйте отклонения и проверьте [критерии приёмки](acceptance.md).

## Пример описания подключения в игре

Пример ниже иллюстративный: платформы, диапазоны, defaults и имена параметров запуска не становятся требованиями к другим играм.

```markdown
# Настройки проекта: условная гонка

Пакеты: menu-base 0.1.0, settings 0.1.1.
Ревизия шаблонов: <точный commit>.
Платформы: Windows, macOS.

## Разделы

- Экран: режим окна, разрешение с Auto, VSync, ограничение FPS.
- Графика: качество, сглаживание, тени.
- Звук: общая громкость, музыка, двигатели, эффекты.
- Управление: чувствительность стика, мёртвая зона, вибрация.
- Общее: язык, масштаб интерфейса, повышенный контраст, FPS.

## Пример контракта одной опции

Ключ: audio.music.
Название: Музыка.
Группа: Звук.
Default: 70%.
Диапазон: 0–100%, шаг 1%.
Область: устройство.
Применение: сразу и автоматическое сохранение.
Ноль отключает только музыку.

Аналогичная запись заполняется для каждой применимой опции.

## Неприменимые опции

Речь и субтитры: в игре нет речи.
Инверсия и скорость камеры: камера автоматически следует за машиной.
Чувствительность мыши и игровой курсор: мышь используется только в меню.
Помощь управлению: такая механика не предусмотрена.
Здоровье: у машин нет здоровья.
Ping: сетевой режим показывает его по пользовательскому выбору.
Статистика: внешняя отправка отсутствует.
Очистка данных: такой операции в этом пакете нет.

Все строки каталога разобраны в проектной таблице опций.

## Входы, хранение и сброс

Главное и игровое меню предоставляют одинаковые настройки.
Исключений нет. Все предпочтения сохраняются на устройстве.
Место хранения: <путь или storage key>.
Смена экрана требует подтверждения с автоматическим откатом.
Сброс раздела назначен на верхнюю кнопку pad; Xbox glyph — Y.
Сброс всех предпочтений — отдельное экранное действие.

## Тихий запуск

Техническая опция: -muted; для Unity дополнительно -noaudio.
Для браузерной поставки: ?muted=1 до autoplay.
Команда/URL: <точная команда запуска или URL проекта>.
Вывод отключён до первого воспроизведения.
Сохранённые пользовательские громкости не меняются.

## Справка

Страница 1: клавиатура и мышь.
Страница 2: геймпад.
Игровые действия: газ, тормоз, поворот, занос, нитро, пауза.
Навигация по меню не описывается.
Основные изображения генерируются в стиле игры.
Источник назначений: <актуальная таблица input actions проекта>.

Отклонения: нет.
```

## Проверка полноты

Описание проекта должно позволять реализовать настройки без угадывания defaults и областей действия. После подключения обновите его фактическими значениями и результатами приёмки. Новая ревизия общих шаблонов применяется отдельной задачей; существующая игра не меняется автоматически.
