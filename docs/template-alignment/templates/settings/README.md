# Настройки

Пакет: `settings`. Версия: **0.1.1**. Зависимость: [menu-base](../menu-base/README.md) **0.1.0**.

Задаёт пользовательские настройки игры: состав типовых опций, группировку, элементы управления, применение, сохранение, сброс и отдельную графическую справку по игровому управлению.

- [Требования](requirements.md)
- [Каталог типовых опций](options.md)
- [Графическая справка](controls-help.md)
- [Критерии приёмки](acceptance.md)
- [Как подключить и пример](usage.md)

Пакет наследует все правила базового меню. Настройки доступны из главного и игрового меню с одинаковым поведением, кроме явно согласованных исключений.

Баланс, параметры матча и лабораторные профили не относятся к пользовательским предпочтениям. Сохранение предпочтений в этом пакете не определяет сохранение и загрузку игрового прогресса.
