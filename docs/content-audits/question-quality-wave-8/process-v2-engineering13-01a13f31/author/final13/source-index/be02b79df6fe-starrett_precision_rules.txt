# Precision Rules
The Starrett Steel rule is the basic measuring tool from which many other tools have been developed.
High Quality Starrett Steel Rules range in size from as small as one-quarter inch in length to many feet long. Steel rules are graduated in the English (Inch) or Metric system for both systems are provided on a single rule.
