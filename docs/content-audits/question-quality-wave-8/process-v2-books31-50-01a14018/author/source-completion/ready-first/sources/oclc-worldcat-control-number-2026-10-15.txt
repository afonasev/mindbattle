L400 # OCLC: OCLC Control Number
L402 Record Type: BIB
L406 Field: ALL: 001
L410 Input Standards: ALL: System supplied. Default: NEW
L414 Definition
L417 OCLC assigns a unique number to each bibliographic record input into WorldCat. You cannot change the control number. On workforms and newly derived records, the word NEW is in the OCLC control number position. The system assigns an OCLC number after Produce or Update Holdings.
