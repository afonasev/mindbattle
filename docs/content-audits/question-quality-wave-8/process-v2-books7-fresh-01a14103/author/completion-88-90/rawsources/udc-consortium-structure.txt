The Consortium describes ten hierarchical main classes numbered 0–9. It distinguishes common auxiliary signs, which connect numbers to express relations, and common auxiliary numbers for recurring characteristics that apply across main tables. The listed common auxiliaries include language, document form, place, ancestry/ethnicity, time, properties, materials, relations/processes and persons. The signs include +, /, :, and ::. Short exact phrase retained: “Common auxiliaries are applicable throughout the main tables.” Its example 37:2 denotes a relation between education and religion. These provisions distinguish UDC from the Colon scheme, which Ranganathan describes as using unit schedules and connecting symbols but not these UDC common-auxiliary tables.
