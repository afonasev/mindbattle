OCLC Introduction to the Dewey Decimal Classification, §§4.1–4.3, pp. 1–3; 2026-10-16 read. Full relevant context: DDC uses Arabic numerals and well-defined hierarchical categories; its broadest level has ten main classes covering all knowledge; each class is divided into ten divisions and each division into ten sections. Main classes are 000 computer science/information/general works, 100 philosophy/psychology, 200 religion, 300 social sciences, 400 language, 500 science, 600 technology, 700 arts/recreation, 800 literature, 900 history/geography. The first digit of a three-digit number represents the main class; decimal extensions continue classification.
