# Вторая волна редакторской проверки Mindbattle

Проверены все 500 актуальных карточек: ключ вместе с полным prompt, explanation и все четыре notes — 3000 точных привязок к прочитанным источникам. Изменены 480 карточек; 20 проверены и оставлены без изменений. Открытых редакторских замечаний в этой версии нет. Ручная приёмка и production deployment пока не выполнены.

[Все 500 карточек для чтения](readable500.md) содержат варианты, ключ, explanation, четыре notes и источник карточки. [Машинный пакет](../question-quality-wave-2.json) связывает каждую из 3000 формулировок с фактическим захватом источника, локатором и независимой проверкой точной версии. В отдельных `*-current-review.json` сохранены текущие поштучные решения. `baseline500.json` — историческая версия до этой волны, а не повторная сертификация.

В итоговых привязках используются 605 различных захваченных тел источников; один прочитанный абзац может обосновывать несколько полей. Для математических карточек формулы и определения проверены по учебным источникам, расчёты пересчитаны. Музыкальные сведения сверены с официальными credits, каталогами исполнителей, музеев, премий и издателей. Исторические институциональные изложения и авторские лекции не называются свидетельствами современников событий.

Первоначальные HOLD, исправления, полные поздние проверки и тела источников сохранены отдельно в `/Users/eaafonasev/Projects/mindbattle-planning/evidence/question-quality-wave-2/`. Манифест `editorial-history/preservation-manifest.json` связывает временные первоначальные пути с долговечными копиями и SHA; повторное чтение всех 190 исторических артефактов и 746 сохранённых путей источников проверено. Тексты источников не включены в Git-пакет целиком.

Свежий каталог содержит 110 тем / 11000 карточек / 121000 текстовых полей. Автоматические очереди — кандидаты, а не фактические дефекты. Все 82 текущих критических кандидата, затрагивающих эту волну, разобраны содержательно; основные факты новых исторических вопросов дополнительно независимо сравнены с полным каталогом. Подтверждённые дубли и обратные вопросы этой волны устранены. Остальные 105 тем не изменены и не получили новой фактической сертификации. Прежние принятые 500 карточек и пилотные 20 защищены целиком, включая source metadata.

Проверки: `python3 scripts/verifyQuestionQualityWave2.py`, `npm run content-check`, `npm run check` (202 unit-теста и сборка), strict OpenSpec. Полный browser-suite оценивается относительно свежего main baseline с 25 исходными падениями; его точное сравнение и логи записаны в planning evidence. Отдельно проверены реальные раскрытия пяти тем на 1280×720 и 390×844, точные тексты explanation и трёх видимых неправильных notes, отсутствие ошибок страницы и горизонтального обрезания. Все четыре notes остаются в корпусе; интерфейс показывает справки только к трём неправильным вариантам. Настройки звука проверены выключенными через UI. Узкая арена ответов по существующему CSS шире внутренней question-stage на 16px, однако все проверенные тексты и варианты помещаются в viewport; внутренний overflow metric сохранён без объявления его зелёным.

PNG, seed/state и QA JSON лежат в `evidence/question-quality-wave-2/browser/`. Проведена также реальная UI-проверка мировой поп-музыки во встроенном Browser, с ответом и раскрытием справок. Это автоматическая и визуальная проверка контента, не физическая приёмка телефонов или игровых контроллеров.
