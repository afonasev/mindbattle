# Последовательная редактура в одном чате — 2026-11-02

Поручение пользователя: улучшать оставшиеся вопросы по требованиям, без координатора, новых исполнителей и согласования каждой карточки. Автор и владелец этого среза: `01a19d6a-35c2-7a73-97b5-2696979f8eac`.

Цикл: одна карточка → чтение источников и соседних вопросов → согласованная редакция prompt, вариантов, explanation и четырёх notes → самостоятельная содержательная сверка → минимальные проверки. Обычные редакторские решения агент принимает самостоятельно. Исторические HOLD/FAIL, ограничения источников и квоты сохраняются. Самопроверка не называется независимым review и не увеличивает CURRENT.
