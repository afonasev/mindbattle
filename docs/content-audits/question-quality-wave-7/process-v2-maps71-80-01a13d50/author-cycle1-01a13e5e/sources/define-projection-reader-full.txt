L14: ## Summary
L15: 
L16: Overwrites the coordinate system information (map projection and datum) stored with a dataset. This tool is intended for datasets that have an unknown or incorrect coordinate system defined.
L17: ## Usage
L18: 
L19:   * All geographic datasets have a coordinate system that is used throughout ArcGIS to display, measure, and transform geographic data. If the coordinate system for a dataset is unknown or incorrect, you can use this tool to specify the correct coordinate system.
L20: 
L21:   * This tool only updates the existing coordinate system information; it does not modify any geometry. To transform the geometry to another coordinate system, use the cite6†Project tool.
L22:   * When a dataset with a known coordinate system is input to this tool, the tool will issue a warning message but will run successfully.
L23: 
L24:   * All feature classes in a geodatabase feature dataset are in the same coordinate system. The coordinate system for a feature dataset should be determined when it is created.
L25: 
L26:   * The tool does not support the following:
L27:     * A feature class in an enterprise geodatabase.
L28:     * A feature class in a feature dataset.
L29:     * A feature dataset that contains a feature class.
L30: 
L31:   * The tool will update the associated .wld file of a CAD or BIM file to retain the data's geographic adjusted position.

L53: 
L54: DefineProjection example 1 (Python window)
L55: 
L56: The following Python window script demonstrates how to use the DefineProjection function in immediate mode.
L57: 
L58:     `import arcpy
L59:     infc = r"C:\data\citylim_unk.shp"
L60:     sr = arcpy.SpatialReference("NAD 1983 UTM Zone 11N")
L61:     arcpy.DefineProjection_management(infc, sr)`
L62: 
L63: DefineProjection example 2 (stand-alone script)
L64: The following stand-alone script uses the DefineProjection function to record coordinate system information for the input dataset.
L65: 
L66:     `# Name: DefineProjection.py
L67:     # Description: Records the coordinate system information for the specified input dataset or feature class
L68: 
L69:     # import system modules
L70:     import arcpy
L71: 
L72:     # set workspace environment
L73:     arcpy.env.workspace = "C:/data"
L74: 
L75:     try:
L76:         # set local variables
L77:         in_dataset = "citylim_unk.shp" #"forest.shp"
L78:         # get the coordinate system by describing a feature class
L79:         dsc = arcpy.Describe("citylim_utm11.shp")
L80:         coord_sys = dsc.spatialReference
L81: 
L82:         # run the tool
L83:         arcpy.DefineProjection_management(in_dataset, coord_sys)
L84: 
L85:         # print messages when the tool runs successfully
L86:         print(arcpy.GetMessages(0))
L87: 
L88:     except arcpy.ExecuteError:
L89:         print(arcpy.GetMessages(2))
L90: 
L91:     except Exception as ex:
L92:         print(ex.args[0])`
