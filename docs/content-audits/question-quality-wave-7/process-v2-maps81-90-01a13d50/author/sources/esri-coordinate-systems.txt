L3: # Coordinate systems, map projections, and transformations
L5: Spatial data includes numerical information that allows it to be positioned on Earth; a coordinate system provides a frame of reference to locate features.
L10-L14: Horizontal coordinate systems locate data across Earth's surface; geographic coordinates are usually longitude and latitude in angular units.
L16: Projected coordinates are planar and use linear measurements; projection calculations convert angular geodetic coordinates to Cartesian planar coordinates.
L21: Geographic coordinates use angular units, whereas projected coordinates use linear units.
L35-L37: A map projection displays coordinate-system data on a flat surface. No projection can flatten the curved Earth without some distortion; some projections preserve area, others local angles, and others specific distances or directions.
