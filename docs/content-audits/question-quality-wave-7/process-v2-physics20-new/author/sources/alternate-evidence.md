# Альтернативные источники и полные capture-контексты

OpenStax исключён из семантической проверки. Для альтернатив выполнены последовательные `/usr/bin/curl --location --max-time 45 --max-filesize 15000000` запросы с обычной TLS-проверкой, `Accept-Encoding: identity`, без retry и без отключения TLS. Все 33 записи манифеста имеют `curlExit=0`, HTTP 200 и `complete=true`; файлы заголовков/тела и SHA-256 сохранены в `curl-captures/capture-manifest.json`. NOAA использует уже сохранённое исходное полное тело; оно не требуется повторно для проверки.

Транспортная целостность подтверждает сохранность ответа, но сама по себе не доказывает утверждения. `candidate.json` и `claim-reviews.json` содержат ссылки и locators на контекст каждого проверенного поля; course index/список тем не засчитываются как factual support. Состояние всех источников и метаданные полных ответов включены в `candidate.json`.

## Особые исходы

- Во время первого bounded списка URL произошёл один неожиданный повторный запрос NOAA-CORIOLIS из-за дубликата в списке. Повторное тело/заголовки удалены, сохранён прежний 83 079-байтовый NOAA capture с SHA-256 `ddcd983ad33bf012ff7e06ac7f24d4213c5c681eaf7cb5e31d3a69e2b9f53ff5`; инцидент отмечен в манифесте.
- `MIT-FLOW-RATE` оказался PDF об электрических bond graphs и RC-цепи; он не доказывает определение объёмного расхода. Соответствующие три поля оставлены HOLD.
- Прямой контекст не подтверждён для эффекта Доплера, передачи внешнего давления по закону Паскаля, закона Торричелли, общего утверждения об энергии связи, определения давления как F/A и определения длины волны. Эти поля оставлены HOLD.
- Фотоэффект, резонанс и интерференция дополнительно сверены с полными первичными PDF MIT, добавленными в capture-манифест; это сняло эти конкретные блокеры, но не заменило независимый CURRENT.
