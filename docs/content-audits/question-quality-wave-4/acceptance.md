# Ручная приёмка четвёртой волны

Приёмка ожидается. Проверять нужно точный опубликованный main commit из publication.json в долговечной evidence-папке. Этот документ не записывает решение пользователя.

## Проверка содержимого

1. Откройте README.md и readable500.md рядом с этим файлом. Там все 500 полных карточек: prompt, варианты, correctIndex, explanation, четыре notes и источник.
2. Оцените однозначность вопроса, взрослую сложность, сопоставимость вариантов и полезность каждой справки именно о своём варианте.
3. Для спорного поля используйте машинный аудит и независимый review artifact; durableCapture и independentPassageCapture ведут к реально прочитанным оригинальным абзацам. Хэш подтверждает версию, а не правильность.
4. Дополнительно проверьте поздние исправления: компьютеры, карточка 7, note 0; кино, карточки 0 и 10. Первоначальные HOLD и пропущенные дефекты сохранены.
5. Сообщите решение о точном commit либо конкретный ID карточки, поле и замечание.

## Визуальная проверка

Десять снимков получаются через реальный встроенный Browser на 1280×720 и 390×844 с выключенным звуком и сбором обратной связи. Для каждого выбран неправильный ответ, чтобы раскрылись основное объяснение и три справки неправильных вариантов. Correct note отдельно текущим UI не отображается; она проверяется в readable500/audit.

| Тема | Seed | Карточка |
|---|---|---|
| Мировое кино | 1-0 | world-cinema-ext-barbie-director |
| Путешествия и географические открытия | 23-0 | world-exploration-gagarin-space |
| Компьютеры и интернет | 24-0 | computers-internet-screenshot |
| Продукты, специи и ингредиенты | 40-0 | food-ingredients-10-1 |
| История Италии | 5d-0 | history-italy-medium-02-10 |

Локальный seed fixture описан в iab-qa-fixture-definition.json. Игра и её JS/CSS/SW не изменены. Это браузерная проверка размеров, а не приёмка физических телефонов/контроллеров. Строка общего catalogRevision наследует wave-3; точность этой волны задают commit, SHA пяти файлов и полных карточек.

## Известные ограничения

Полный браузерный suite на исходном main имеет 25 падений и 5 пропусков; результат этой волны должен сравниваться по названиям и фактическим причинам. Совпадение с baseline не делает suite зелёным. Production не развёрнут.
