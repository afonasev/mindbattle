[Все 500 карточек](readable500.md) содержат четыре варианта, ключ, explanation, все четыре notes и источник. [Машинный аудит](../question-quality-wave-4.json) связывает точные полные карточки и3000 полей с источниками, локаторами фактически прочитанных абзацев и независимыми решениями. Хэши устанавливают версию; фактическая правильность, сложность и качество вариантов подтверждаются содержательными решениями редакторов.

Итоговые привязки используют 469 уникальных SHA исходных тел авторских источников и 461 URL. Один прочитанный абзац может поддерживать несколько полей. Исторические описания музеев и учреждений, оригинальные справочные публикации и техническая документация классифицированы по своему реальному виду; они не выданы за свидетельства очевидцев или чтение всей цитируемой библиографии.

Пять справок кино и одна справка компьютеров, пропущенные первоначальной независимой проверкой, выявлены content-check и последующим содержательным разбором, исправлены по реально прочитанным источникам и снова независимо проверены. Первоначальный PASS и падение content-check сохранены; валидатор и тестовый контракт не менялись.

Исходные HOLD, ошибки получения источников, разногласия источников, поздние исправления и ошибки самого root сохранены в долговечном манифесте истории. Черновые root-проверки компьютеров с неверной индексацией/устаревшими SHA исключены из итогового PASS. Наблюдавшееся изменение динамических тел источников сохранено без необоснованного указания виновника. Ошибочно поднятое root замечание о календарном десятилетии Chrome снято по реально прочитанной хронологии и тоже сохранено.

Свежий скан покрывает 110 тем, 11 000 карточек и 121 000 текстовых полей: 9123 основных/обратных кандидата и 16 485 текстовых кандидатов. Семь текущих критических пар проверены содержательно по полным карточкам; перенесены только решения при точной идентичности обоих объектов. Подтверждённых оставшихся повторов запрошенного core в этой волне нет. Выдача кандидатов не означает новое прочтение или фактическую сертификацию всех 11 000 карточек.

Квоты40easy/40medium/20hard и распределение ключей10/10/5 на позицию сохранены; разрешённые компенсационные пары используют одинаковый correctIndex. IDs, порядок и ключевые позиции не менялись. Предыдущие1500 полных карточек и20пилотных, включая metadata источников, защищены. Остальные105 файлов тем неизменны и не получили новой фактической сертификации.

Точные привязки и защищённые байты: PASS. content-check: 2/2 PASS. npm run check: 202/202 теста, typecheck и build PASS. Strict OpenSpec: PASS. Полный feature browser suite: 78 PASS / 25 FAIL / 5 SKIP, exit 1. Все 25 названий и фактических основных причин совпали со свежим исходным main; новых падений нет. Suite остаётся FAILED.

[Десять реальных снимков Browser](screenshots.md) сохранены и визуально просмотрены. DOM prompt, explanation и ассоциации трёх wrong notes точно совпали с текущими карточками. На 390×844 длинные раскрытия требуют вертикальной прокрутки; верхние состояния также сохранены. Горизонтального переполнения в пяти проверенных раскрытиях нет. Консоль warning/error пуста.

Проверка Browser использует реальные действия во встроенном Browser, неизменённую собранную игру и явно описанный локальный fixture для seed/пустого одноразового профиля. Это не проверка физических телефонов или игровых контроллеров. UI текущего main показывает основное explanation и три справки к неправильным вариантам; правильная справка проверена в каталоге/аудите и отдельно не отображается.

Точная публикация: evidence/question-quality-wave-4/publication.json в общем planning root. Файл записывается после feature push/readback, интеграции, повторных gates и main push/readback; этот Git-артефакт описывает проверенный результат до коммита и не подменяет запись публикации.

Ручная приёмка точной опубликованной версии ожидается. Production deployment не разрешён и не выполнялся. Статус после интеграции фиксируется в delivery.json; разрешённая граница — merged с ожидаемой ручной приёмкой, без finalize/deployed/archive.
