## Context

Рекорды сейчас вложены в общий `mindbattle:data:v1`: сбой его декодирования стирает всю структуру.

## Goals / Non-Goals

- Goals: независимый ключ, идемпотентная миграция, сохранение текущего API рекордов.
- Non-Goals: серверная синхронизация и восстановление уже очищенных Safari-данных.

## Decisions

- Использовать `mindbattle:solo-records:v1` с массивом валидируемых записей.
- При чтении нового ключа считать его авторитетным, даже если он пуст.
- При его отсутствии перенести валидный массив из legacy-ключа и сохранить новый ключ.

## Risks / Trade-offs

Удаление PWA или очистка данных Safari всё ещё удаляет device-local записи.
