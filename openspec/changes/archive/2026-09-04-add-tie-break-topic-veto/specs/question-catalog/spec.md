## ADDED Requirements

### Requirement: Финальный список тем воспроизводимо допустим
Система SHALL для каждого финального списка формировать N+1 различных тем, содержащих хотя бы один допустимый hard-вопрос, где N — число текущих претендентов. Планировщик MUST исключать темы, уже зафиксированные в текущей партии, и обновлять seeded-состояние только воспроизводимым выбором списка, но не выбором его оставшейся темы.

#### Scenario: Список для двух претендентов
- **WHEN** в финальном тай-брейке участвуют две команды
- **THEN** планировщик возвращает три различные допустимые темы, а hard-вопрос выбирается только из темы, оставленной их запретами

#### Scenario: Недостаточно допустимых тем
- **WHEN** каталог не может предоставить N+1 разных тем с допустимыми hard-вопросами
- **THEN** планировщик диагностирует исчерпание до изменения авторитетного состояния партии
