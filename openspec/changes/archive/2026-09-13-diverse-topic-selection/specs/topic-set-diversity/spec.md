## Purpose

Определяет проверяемое разнообразие тематических областей в каждом предлагаемом наборе тем, не нарушая воспроизводимость seeded-выбора.

## ADDED Requirements

### Requirement: Набор тем разнообразен по явной области
Каждая тематика каталога SHALL иметь ровно одну валидируемую область. При формировании обычного, бонусного или финального набора планировщик MUST выбирать темы из разных областей, если число доступных областей не меньше требуемого размера набора. Если доступных областей меньше размера, планировщик SHALL минимизировать число повторов области, прежде чем применять существующий seeded tie-break и приоритет менее показанных тем.

#### Scenario: Три обычные темы при достаточном числе областей
- **WHEN** для обычного выбора доступны темы минимум из трёх областей
- **THEN** три возвращённые темы принадлежат трём разным областям

#### Scenario: Набор больше числа доступных областей
- **WHEN** требуется больше тем, чем доступно областей среди допустимых тем
- **THEN** набор содержит максимальное возможное число разных областей, не повторяет идентификатор темы и не исключает допустимые темы вне существующих правил

#### Scenario: Повторный seeded-расчёт
- **WHEN** одинаковые каталог, история выбора и random-state повторно формируют набор тем
- **THEN** идентичны порядок тем, следующий random-state и факт fallback по областям
