## MODIFIED Requirements

### Requirement: Скрытые ответы раскрываются одновременно
Клиент MUST не подсвечивать выбранную позицию до общего раскрытия и SHALL после раскрытия показать правильный ответ, использованные неправильные ответы, ромбы команд, результаты карточек и основное объяснение. Четыре варианта SHALL образовывать геометрически центрированный крест, а текст каждого варианта SHALL быть центрирован внутри карточки независимо от командных маркеров. После основного объяснения клиент SHALL показать отдельные краткие справки только для тех неправильных вариантов, которые выбрала хотя бы одна команда в текущем вопросе, без повторения одной справки для нескольких команд.

#### Scenario: Команда не ответила
- **WHEN** команда исчерпала время без ответа
- **THEN** её карточка показывает ошибку и «Без ответа» без ромба на вариантах и без создания справки для невыбранного ответа

#### Scenario: Выбран один неправильный вариант
- **WHEN** одна или несколько команд выбрали один и тот же неправильный вариант
- **THEN** после объяснения правильного ответа интерфейс один раз показывает подписанную названием варианта справку о нём

#### Scenario: Выбраны разные неправильные варианты
- **WHEN** команды выбрали два или три разных неправильных варианта
- **THEN** интерфейс показывает по одной справке для каждого фактически выбранного неправильного варианта в стабильном порядке вариантов, равномерно распределяя карточки по всей доступной ширине без зарезервированной пустой колонки справа

#### Scenario: Все ответили правильно
- **WHEN** ни одна команда не выбрала неправильный вариант
- **THEN** интерфейс не показывает блок справок о неправильных вариантах

#### Scenario: Приватность между партиями
- **WHEN** вопрос завершён и локальное состояние партии заменено
- **THEN** выборы команд не добавляются в difficulty-feedback событие и не сохраняются как историческая аналитика ответов
