## Why

Mindbattle имеет утверждённые продуктовые правила, но репозиторий пока не содержит запускаемого приложения. Нужен минимальный browser-клиент, который закрепит выбранный React/TypeScript/Vite-стек и даст проверяемую основу для последующих независимых changes игрового ядра, контента, ввода и экранов.

## What Changes

- Создать запускаемый offline-first browser-клиент на React, TypeScript и Vite для актуального desktop Chromium.
- Создать DOM/CSS shell в утверждённом тёмном направлении интеллектуальной телеарены с локально поставляемыми базовыми стилями.
- Ввести стабильные каталоги `domain`, `application`, `adapters`, `ui`, `content` и запретить UI-зависимости в чистом доменном слое.
- Настроить Vitest, browser smoke-проверку и команды build/test без backend, аккаунтов, аналитики и сетевых runtime-зависимостей.
- Исправить OpenSpec rule id `specs`, чтобы delta-spec требования действительно применялись CLI.
- Не реализовывать в этом change правила партии, каталог из 900 вопросов, маршрутизацию физических контроллеров, звук или полный игровой поток.
- Открытых продуктовых решений, блокирующих change, нет.

Затронуты утверждённые разделы `docs/GAME_SPEC.md`: «Утверждённое видение», «Визуальное направление», «Техническая платформа», «Технические и проверочные инварианты». Игровое умение, скрытая информация, время, очки, elimination, comeback и tie-break в этом инфраструктурном change не изменяются.

## Capabilities

### New Capabilities

- `browser-client-foundation`: запускаемый и проверяемый локальный Chromium-клиент с утверждёнными технологическими и архитектурными границами.

### Modified Capabilities

- Нет.

## Impact

- Новые project/runtime/test конфигурации и исходные каталоги browser-клиента.
- Новые зависимости React, Vite, TypeScript, Vitest и средства browser smoke-проверки.
- Локальный статический build без внешнего сервера и сетевых API.
- Последующие changes будут зависеть от зафиксированных каталогов, test scripts и UI shell.
