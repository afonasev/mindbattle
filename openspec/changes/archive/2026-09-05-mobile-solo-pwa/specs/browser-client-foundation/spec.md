## MODIFIED Requirements

### Requirement: Стартовый интерфейс соответствует утверждённому направлению

Клиент SHALL отображать DOM/CSS-интерфейс в направлении современной тёмной интеллектуальной телеарены и MUST сохранять читаемую композицию в диапазоне desktop 16:9 от 1280×720 до 1920×1080. На мобильной ширине до 760 CSS-пикселей клиент SHALL предоставлять phone-first меню соло-забега без видимого старта классической командной партии и MUST сохранять крупный контрастный текст без вида корпоративного dashboard.

#### Scenario: Просмотр стартового shell
- **WHEN** клиент открыт при поддерживаемом desktop viewport
- **THEN** пользователь видит название Mindbattle, ясное основное действие и крупный контрастный текст без вида корпоративного dashboard

#### Scenario: Просмотр mobile shell
- **WHEN** клиент открыт на viewport шириной 390 CSS-пикселей
- **THEN** пользователь видит phone-first вход в соло-забег без элементов запуска классической командной партии
