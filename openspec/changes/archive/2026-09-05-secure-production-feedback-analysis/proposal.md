## Why

Фидбэк уже отправляется same-origin API и хранится на production VPS, но его агрегированная сводка доступна любому посетителю сайта, а редакторский отчёт читает устаревший локальный v1-снимок. Нужен единый production-журнал, в который могут писать игры с разных устройств, но анализ которого доступен только владельцу сервера по SSH.

## What Changes

- **BREAKING** Удалить публичную HTTP-сводку feedback и запретить выдачу журнала, агрегатов и заметок через web origin.
- Сохранить анонимный idempotent same-origin `POST` для записи v3-событий из игры на любом устройстве.
- Добавить воспроизводимый SSH-only отчёт по production NDJSON-журналу: v3-показы, жалобы, отсутствие жалоб, доля жалоб, причины, диагностические строки и ревизии каталога.
- Обновить production deployment и документацию: raw-журнал и результат отчёта хранятся за пределами web-root и не синхронизируются в репозиторий.
- Обновить каноническую спецификацию и `docs/GAME_SPEC.md`: production persistence является утверждённым контуром, автоматическая переклассификация по-прежнему не входит в scope.

## Capabilities

### New Capabilities

- Нет.

### Modified Capabilities

- `difficulty-feedback`: server-side журнал и агрегаты становятся доступными для анализа только через SSH, при сохранении публичной записи анонимных событий.
- `question-catalog`: редакторский отчёт читает production v3-журнал и формирует ручные сигналы без автоматического изменения каталога.
- `browser-client-foundation`: production same-origin runtime принимает запись feedback с любого устройства без добавления аккаунтов, внешней аналитики или device-идентификаторов.

## Impact

- `server/index.mjs`, `server/feedbackStore.mjs`, production systemd/Caddy deployment и healthcheck.
- Новый или заменённый Node CLI-отчёт и его unit-тесты; текущий v1-only `content:feedback-report` больше не является источником production-аналитики.
- `README.md`, `docs/GAME_SPEC.md` и три связанных OpenSpec capability-spec.
- Игровые правила, очки, таймеры, состав команд, скрытая информация, случайность, tie-break, ввод и UI не меняются. Нет аккаунтов, идентификации устройств, передачи игрового состояния между устройствами, фоновой телеметрии и автоматической правки каталога.
- Открытых продуктовых решений нет: пользователь утвердил SSH-only чтение и отсутствие публичного доступа к аналитике.
