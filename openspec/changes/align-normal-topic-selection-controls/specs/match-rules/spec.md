## MODIFIED Requirements

### Requirement: Обычная тема выбирается честно
Система SHALL воспроизводимо выбирать первую команду по seed и передавать право выбора по циклу так, чтобы разница числа обычных выборов между командами не превышала одного. Перед фиксацией темы система SHALL хранить курсор активной выбирающей команды на одной из трёх доступных тем; влево и вправо циклически перемещают только этот курсор, а вниз фиксирует текущую тему. После фиксации доступной темы система SHALL создать трёхсекундную подготовительную фазу, в которой вопрос ещё не начат; только её окончание либо допустимый ручной пропуск начинает общий вопрос для всех команд.

#### Scenario: Навигация по трём темам
- **WHEN** активная команда перемещает курсор влево или вправо
- **THEN** ядро воспроизводимо меняет только индекс текущей темы в пределах трёх карточек
- **AND** seed, доступные темы, очки и запас времени не изменяются

#### Scenario: Выбор одной из трёх тем
- **WHEN** активная команда подтверждает текущую тему действием вниз
- **THEN** ядро фиксирует тему под курсором и открывает трёхсекундную подготовительную фазу с её названием

#### Scenario: Неактивное направление
- **WHEN** активная команда создаёт действие вверх на экране обычных тем
- **THEN** ядро игнорирует действие без изменения состояния

#### Scenario: Подготовительная фаза завершается по времени
- **WHEN** три секунды авторитетного времени подготовки истекли без паузы
- **THEN** ядро начинает общий вопрос и только с этого момента запускает базовый таймер ответа

#### Scenario: Ручной пропуск
- **WHEN** после neutral gate любая активная команда создаёт новое допустимое действие продолжения
- **THEN** ядро немедленно начинает тот же общий вопрос без изменения темы, seed, очков или запаса времени

#### Scenario: Пауза подготовки
- **WHEN** партия приостановлена во время подготовки
- **THEN** остаток трёхсекундного отсчёта не изменяется до продолжения

#### Scenario: Действие неактивной команды
- **WHEN** другая команда пытается переместить или подтвердить тему
- **THEN** ядро игнорирует действие без изменения состояния
