## Context

Мотивация и область: proposal.md. Чистые createMatch/reduceFrame и CatalogDomainContext уже отделены от браузера. GameController связан с localStorage; UI classic принимает секретный MatchState, поэтому его нельзя использовать как сетевой протокол. Node runtime уже обслуживает same-origin API. Архитектурный read-only review выполнен astra_architect.

## Goals / Non-Goals

**Goals:** переиспользовать правила, добавить серверную комнату и безопасные отдельные проекции, сохранить локальное поведение.

**Non-Goals:** distributed hosting, аккаунты, перенос личности на другой браузер, абсолютная секретность публично доступного offline-каталога, миграция локальных сохранений в сеть.

## Decisions

- Новый профиль network-v1 расширяет ID участников независимо от четырёх локальных цветов. Ядро хранит стабильный ring состава и departed IDs; активная очередь фильтрует ring, сохраняя следующий обычный выбор. Бонус читает максимум четыре ID без продвижения ordinal.
- Повторно используем ядро и серверный CatalogDomainContext, а не переносим браузерный GameController и не дублируем движок. Сетевой тай-брейк следует каноническому GAME_SPEC: сложный вопрос без выбора темы. Существующий local final-veto не меняется в этой фиче.
- Транспорт SSE для server snapshots + POST для команд, без новой транспортной библиотеки. Соединение имеет generation, heartbeat lease, серверный timestamp и последовательную обработку. POST несёт token, command ID, epoch и phase revision; повторные и устаревшие команды не действуют. Secret не помещается в URL: stream открывается fetch с заголовком авторизации.
- Код комнаты — случайные четыре цифры, уникальные среди живых комнат. Organizer/player capability tokens криптографически случайны, сохраняются только на соответствующем устройстве. Имена ограничены 24 символами, создание/вход — 60 запросами в минуту с одного IP, сервер — 32 комнатами; лимиты ограничивают ресурсы. Сервер проверяет права, не доверяя client teamId или времени.
- Сервер монотонно продвигает время; tick рассылает актуальные остатки. Пауза включает ручную и потери устройств; восстановление оставляет ручное ожидание ведущего. Нельзя resume при unresolved disconnect. Старый stream не отключает заменивший его stream.
- Снимок общего экрана содержит публичные карточки, мобильный — только свою карточку, собственный ответ и необходимые доступные действия. Правильный ответ/объяснения появляются после reveal. Не передавать MatchState, seed, answerOrder или каталог через network API. Сетевой route загружается отдельно от локального приложения; существующий offline-каталог остаётся доступным через локальный продукт, это не защита от намеренного изучения каталога.
- Исключение хранит очки, удаляет игровое право и пересчитывает фазу, contenders и подготовленное продолжение. В бонусе сбрасываются запреты; при неизменном числе кандидатов темы сохраняются. Завершение из-за одного активного имеет отдельную причину, не объявляет исключённого победителем.
- Комната переживает перезагрузку клиентской страницы в рамках server runtime. Durable restart сервера не является согласованной гарантией; потеря runtime даёт ясное сообщение о недоступной комнате. Idle-комнаты удаляются после 24 часов без соединений; heartbeat 2 секунды, lease 8 секунд.
- Серверная сборка TypeScript bundle выполняется рядом с client build; API не кешируется PWA. Активная сеть блокирует предложение применения обновления. Звук запускается только после пользовательского жеста на общем экране.

## Risks / Trade-offs

- SSE/POST может задерживаться мобильной сетью → подтверждать ответ по server snapshot, игнорировать устаревшие команды, измерить реальную синхронизацию.
- Мобильный фон приостанавливает transport → heartbeat и общая пауза вместо продолжения таймеров без игрока.
- Короткий код не является секретом → capability tokens защищают существующие роли; ограничение join/create от перебора и злоупотребления.
- 12 панелей уменьшают свободное место → адаптивная сетка, имена и номера, визуальная проверка 12 игроков.
- Автоматические клиенты не доказывают работу физических телефонов → отдельный обязательный physical playtest до заявления полной доставки.

## Migration Plan

Добавить профиль и API, собрать серверный bundle, выполнить unit/integration/browser проверки и физический плейтест. Синхронизировать delta, выделенный commit. Rollback возвращает предыдущую версию приложения; активные сетевые комнаты прекращаются, локальные сохранения совместимы.
