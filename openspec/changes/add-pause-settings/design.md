## Context

См. `proposal.md` и delta specs. Classic и solo уже имеют локальные pause-overlay, а network-v1 имеет раздельные display и player-представления. Preferences локальны и presentation-only; MatchState и room snapshot не должны получать новый тип команды.

## Goals / Non-Goals

**Goals:**

- Дать единый путь «пауза → настройки → та же пауза» во всех режимах.
- Переиспользовать существующие элементы preferences, не дублируя правила сохранения.
- Сохранить network-власть и frozen-состояние комнаты.

**Non-Goals:**

- Не менять доменные правила, серверный API, протокол, таймеры, seed или сохранённые снимки партии.
- Не добавлять настройки, которых нет в главном меню.
- Не давать телефоном неведущего управлять общей сетевой сессией.

## Decisions

- Выделить переиспользуемую presentation-only панель настроек с явным `back`, а pause-overlay оставить владельцем состояния паузы. Это исключает повторную логику preferences между режимами.
- В classic и solo переход открывается из существующего локального overlay; закрытие панели восстанавливает overlay, а не игровой экран. Альтернатива с отдельным route была отклонена: она сложнее для сохранения фокуса и паузы.
- В network-v1 отображать действие только тем поверхностям, которым уже разрешена пауза. Изменения preferences остаются локальными для устройства; комнатная команда не создаётся.
- Тестировать через mute URL: audio не является объектом этой проверки.

## Risks / Trade-offs

- [Разные разметки classic, solo и network расходятся] → вынести общую панель, но покрыть каждый вход и возврат browser-сценарием.
- [Возврат случайно продолжает таймер] → хранить открытие настроек только как дочернее представление уже активной паузы и проверять неизменность фазы.
- [Настройки network ошибочно становятся общими] → не расширять NetworkAction и отдельно проверить неведущего игрока.

## Migration Plan

1. Добавить общий presentation-only экран настроек и точки входа из пауз.
2. Проверить classic, desktop/mobile solo и network display/ведущего; отдельно убедиться, что обычный телефон не получает управление.
3. При откате удалить новые точки входа: сервер, данные комнаты и сохранённые партии совместимы без миграции.
