## ADDED Requirements

### Requirement: Претенденты независимо управляют финальными запретами
Система SHALL на финальном списке тем принимать `влево/вправо` для курсора, отдельное подтверждение для установки или замены запрета и `вверх` для снятия запрета только от текущих претендентов. После определения финальной темы любое удержанное действие MUST пройти neutral gate; новое допустимое действие претендента создаёт только продолжение подготовительной фазы.

#### Scenario: Ввод зрителя
- **WHEN** команда-зритель действует на финальном списке или подготовительном экране
- **THEN** адаптер не создаёт игровую команду и состояние партии не меняется

#### Scenario: Удержание определяющего запрета
- **WHEN** действие претендента определяет единственную финальную тему и остаётся удержанным
- **THEN** оно не пропускает подготовительный экран до отпускания и нового допустимого действия
